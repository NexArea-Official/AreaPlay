# Area Play — Vita Edition: building from source

You need [VitaSDK](https://vitasdk.org) (with the `VITASDK` environment variable set), CMake and Ninja,
plus these VitaSDK packages for HTTPS (updates):

```
vdpm openssl zstd curl
```

(`curl` from vdpm is built against the `openssl` package, OpenSSL 1.0.2: do not install `openssl-1.1.1` instead.)

Build the two companions first, then Area Play (it packs them into its VPK):

```
cmake -S updater -B updater/build -G Ninja -DCMAKE_TOOLCHAIN_FILE="$VITASDK/share/vita.toolchain.cmake"
cmake --build updater/build
cmake -S plugin/areaplay_return -B plugin/areaplay_return/build -G Ninja -DCMAKE_TOOLCHAIN_FILE="$VITASDK/share/vita.toolchain.cmake"
cmake --build plugin/areaplay_return/build
build.cmd          (Windows)
./build.sh         (Linux / macOS / WSL)
```

The VPK is written to `build/AreaPlay.vpk`.

- `src/main.c` includes the files of `src/parties/` (one build unit): do not add them to CMake.
- Files in `assets/` are packed into the VPK automatically.
- `updater/`: Area Play Updater, installed by Area Play itself on first start. Its `sce_sys/package/head.bin`
  is generated by `updater/generer_head.py` from a template taken from VitaDeploy (MIT, see `head_template_LICENSE.txt`).
- `plugin/areaplay_return/`: the optional "back to Area Play after a game" taiHEN plugin, installed by Area Play
  when the option is turned on.
