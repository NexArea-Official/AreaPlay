# Assets Area Play

Dépose ici les ressources graphiques qui seront intégrées au VPK.

## Icônes

Les icônes du menu, des réglages et des boutons sont dans `icons/` : blanc sur fond transparent, 64 × 64 px, dessinées pour Area Play. La liste des noms et l'endroit où chacune apparaît sont dans `icons/ICONES.txt`.

## Polices

Place les fichiers TTF dans `fonts/` :

- `Inter-Regular.ttf` pour les libellés et textes secondaires
- `Inter-SemiBold.ttf` pour les titres et éléments sélectionnés

Prendre les fichiers depuis une distribution sous licence SIL Open Font License. Area Play chargera la police depuis son dossier d'application ; aucune installation sur la console ne sera nécessaire.
