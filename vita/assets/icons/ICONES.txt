Area Play - icones remplacables
==============================

OU LES METTRE
-------------
- Avant la compilation : dans ce dossier (assets/icons/ du projet). Elles sont mises dans le VPK.
- Sans recompiler : sur la console, dans ux0:data/AreaPlay/icons/ (prioritaire sur le VPK).
Ordre de recherche : ux0:data/AreaPlay/icons/<nom>.png, puis assets/icons/<nom>.png,
puis l'ancien nom (colonne de droite), sinon l'icone est dessinee par le programme.

FORMAT
------
- PNG avec transparence. Dessin BLANC sur fond transparent : la couleur est ajoutee par le
  theme (couleur d'accent quand l'element est selectionne, gris sinon).
- Taille conseillee : 64 x 64 pixels (ou plus, carre de preference).
- Le dessin doit occuper toute l'image, sans marge : l'icone est reduite pour que son plus grand
  cote fasse 20 pixels a l'ecran (46 dans les fenetres de confirmation). Une image avec beaucoup
  de vide autour parait petite.
- Apres avoir ajoute ou change une icone : recompiler (assets/icons) ou relancer Area Play (ux0).
